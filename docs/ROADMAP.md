# Roadmap
## V0.1 Foundation
Premium shell, dashboard, equipment registry, logbook, watchlist and quick entry.
## V0.2 Operator memory
Persistent local DB, notes, equipment history, pending actions, timers/reminders and handover.
## V0.3 Camera/OCR
Photo capture, handwritten-note scan, OCR review and equipment-tag dictionary.
## V0.4 Knowledge
Procedure/document library, process circuits, source/version metadata and search.
## V0.5 Private AI
Local/open-weight LLM adapter, vector index, RAG, grounded answers, shift summaries and similar-event retrieval.
## Production hardening
Authentication/RBAC, encrypted sync, audit trail, admin tools, backups, MDM/site deployment, security review and tests.
